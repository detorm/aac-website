# AAC Website

This repository contains the official website for **AAC — Accounting and Auditing Club** at Nazarbayev University.

The website showcases the club’s activities, board members, events, and mission. It is fully responsive and designed to work on both desktop and mobile devices.

---

## 🌟 Features

- **Home Banner** with club introduction
- **About Section** describing the club’s purpose and achievements
- **Board Members Slideshow** with horizontal scroll for mobile and desktop
- **Events and Activities**
- **Responsive Design** using HTML, CSS, and JavaScript
- **Modern UI** with blur and glass effects for header and sliders

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (ES6+)
- [Swiper.js](https://swiperjs.com/) for slideshows
